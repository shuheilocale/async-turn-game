# 企画書：ゆっくり対局（仮）

> 「手紙のやりとりのように、好きなときに一手ずつ」遊べる 2 人用ターン制ボードゲーム

- 作成日：2026-10-22（同日更新：ゲームを 5 本に、隠し情報ゲーム対応、日本語・英語・タイ語対応）
- 状態：たたき台（MVP＝最小限の動く版 は実装済み。`README.md` 参照）

---

## 1. ひとことで言うと

離れた 2 人が、**同じ時間にそろわなくても**遊べる Web のボードゲーム集。
相手が指したら、自分の好きなタイミング（通勤中・昼休み・寝る前など）に一手返す。
1 局が数分で終わることもあれば、数日かけてのんびり進むこともある。

## 2. なぜ作るのか（背景と課題）

| 課題 | 今あるものの不満 |
| --- | --- |
| 生活リズムが違う相手（家族・遠方の友人・忙しい同僚）と時間を合わせにくい | 多くの対戦ゲームは「今この瞬間に 2 人そろう」前提 |
| アプリのインストールやアカウント登録が面倒 | 相手にも同じ手間を強いるので、誘うハードルが高い |
| スマホでも PC でも続きをやりたい | 端末ごとにアプリが分かれている／引き継ぎが面倒 |

→ **「リンクを送るだけで始まり、ブラウザだけで、いつでも一手ずつ」** を満たすものを作る。

## 3. 誰のためか（想定する遊び手）

- **メイン**：時間が合いにくい 2 人（例：単身赴任中の家族、遠方の友人、在宅と出社が違う同僚）
- **サブ**：ちょっとした空き時間に頭を使いたい人
- 想定しない人：ランキングやレートを競いたいガチ勢（将来の拡張で検討）

## 4. 遊び方の流れ

```
[Aさん] トップ画面で「対局を作る」
   ↓ 招待リンクができる
[Aさん] LINE などで招待リンクを Bさんに送る
   ↓
[Bさん] リンクを開いて名前を入れて「参加する」（登録不要）
   ↓
[交互に] 自分の番になったら盤をタップ →「ここに置く」で確定
   ↓ 相手の画面には数秒以内に反映される
[終局] 勝敗が表示される
```

- 自分の番が来ているかは、トップ画面の「参加中の対局」一覧とブラウザのタブ名（● あなたの番）で分かる
- 同じ人がスマホと PC の両方で遊びたいときは「自分用リンク」を自分の別端末で開けばよい

## 5. 「時間をそろえない」ための工夫

| 工夫 | ねらい | 状態 |
| --- | --- | --- |
| アカウントなし・招待リンクだけで参加 | 誘うハードルを最小にする | 実装済み |
| 置く前に「確定ボタン」を挟む | スマホでの押し間違い防止。非同期だと待った（やり直し）が頼みにくい | 実装済み |
| 直前の相手の手を枠で強調 | 時間が空いても「何が起きたか」をすぐ思い出せる | 実装済み |
| 置いたときにひっくり返る石を事前表示 | 考える時間を短くする | 実装済み |
| 自分用リンクで端末をまたぐ | 朝はスマホ、夜は PC のような遊び方 | 実装済み |
| 複数の対局を同時進行、一覧で「あなたの番」を上に並べる | 相手を待つ間も別の対局を進められる | 実装済み |
| **手番の通知（Web プッシュ通知・メール）** | アプリを開かなくても番が来たと分かる。非同期ゲームの肝 | 次の段階 |
| **持ち時間（例：1 手 3 日まで）** | 放置された対局を自動で終わらせる | 次の段階 |
| 棋譜（手の記録）の振り返り再生 | 終局後に会話のネタになる | 将来 |
| ひとことメッセージ（スタンプ） | 一手に気持ちを添える。手紙らしさ | 将来 |

## 6. ゲームのラインナップ

トップ画面にゲームのカードが並び、選んで対局を作る「ゲーム集」の形にしている。
ゲームは大きく 2 種類に分かれる。

- **盤面が全部見えるゲーム**：オセロのように、お互いの情報がすべて見えている
- **相手に隠す情報があるゲーム（かけひき系）**：秘密の数字や手札のように、相手に見せない情報がある。
  時間をそろえずに遊ぶ形と特に相性が良い（相手の出方を考える時間がたっぷりある、対面だと顔に出る駆け引きを落ち着いてできる）

### 実装済み（5 本）

| ゲーム | 種類 | 1 局の長さ | 内容 |
| --- | --- | --- | --- |
| マルバツ | 全部見える | すぐ終わる（最大 9 手） | 3×3 に ○× を置き、3 つ並べたら勝ち |
| 四目並べ | 全部見える | ふつう | 列にコマを落とし、4 つ並べたら勝ち |
| オセロ | 全部見える | じっくり（約 60 手） | 定番 |
| ヒット＆ブロー | 隠す情報あり | ふつう（1 人 10 回まで） | 秘密の 3 桁の数字を当て合う。先手が当てても後手にもう 1 回機会があり公平 |
| 数字のせり | 隠す情報あり | ふつう（9 ラウンド） | 1〜9 のカードをこっそり出し合い、大きい方が得点カードをもらう。同じ数字なら持ち越し |

「数字のせり」は、同時に出し合うゲームを「先に出した人のカードは相手に見せずに預かる」ことで交互の手番に置き換えている。
この方法を使えば、じゃんけんのような「同時に決める」ゲームも時間をそろえずに遊べる。

### 今後の候補

| ゲーム | 種類 | コメント |
| --- | --- | --- |
| 海戦ゲーム（バトルシップ） | 隠す情報あり | 船の配置を隠して撃ち合う。配置の画面（スマホで船を並べる操作）が手間 |
| ドット・アンド・ボックス | 全部見える | 線を引いて箱を取る。連続手番があり非同期と相性良 |
| 五目並べ | 全部見える | 15×15 だとスマホでは拡大表示が必要 |
| ミニ将棋（5×5） | 全部見える | じっくり派向け。駒の画像・持ち駒の表示が必要 |
| 3 人以上のゲーム（人狼など） | 隠す情報あり | 「2 人」前提の部分を広げる改修が必要 |
| オリジナルゲーム | 調整可 | 「非同期ならでは」の要素（例：毎朝盤面が少し変わる）を入れられる |

**用語**：かけひき系（隠し情報ゲーム）＝相手に見せない情報があり、それを推理したり読み合ったりするゲーム

## 7. 機能の範囲

### MVP（今回作った最小限の版）
- 対局の作成（先手・後手・おまかせを選べる）
- 招待リンクでの参加（1 回限り有効）
- 交互に手を指す。不正な手・手番でない人の手はサーバではじく
- 相手の手の自動反映（5 秒ごとに確認）
- ゲーム 5 本（マルバツ・四目並べ・オセロ・ヒット＆ブロー・数字のせり）と、ゲームを選ぶトップ画面
- 隠す情報の保護：相手の秘密はサーバの外に出さない（ブラウザの開発者向け機能で覗いても見えない）。終局後に公開
- 日本語・英語・タイ語の切り替え（最初はブラウザの言語設定に合わせ、画面右上で変更できる）
- 参加中の対局一覧、自分用リンクでの端末引き継ぎ
- スマホ・PC 両対応の画面、ダークモード

### 次の段階（第 2 版）
- 手番の通知（Web プッシュ通知。iPhone はホーム画面に追加すると受け取れる）
- 持ち時間と時間切れ負け
- 投了（降参）ボタン、再戦ボタン
- インターネット上への公開（後述）

### 将来
- 棋譜の再生、ひとことメッセージ
- 任意のアカウント連携（トークンをなくしても復旧できるように）
- 3 人以上のゲーム、観戦の共有リンク

## 8. 技術構成（なぜこれにしたか）

| 部分 | 採用 | 理由 |
| --- | --- | --- |
| 言語 | TypeScript | 画面とサーバで同じ言語・同じルールのコードを共有できる |
| ルール（`packages/core`） | 純粋な関数だけで書いたゲームの決まり | サーバでは不正チェック、画面では置ける場所の表示に同じものを使う。テストしやすい |
| 画面（`apps/web`） | React + Vite | 部品の作りやすさと開発の速さ |
| サーバ（`apps/server`） | Hono（Node.js 上で動く小さな Web サーバの道具） | 軽く、将来 Cloudflare などに移すときも同じコードが使える |
| 保存（データベース） | SQLite（ファイル 1 つで動くデータベース） | 準備がいらない。規模が小さいうちは十分 |
| 相手の手の反映 | 5 秒ごとの確認（ポーリング） | 非同期ゲームでは数秒の遅れは問題にならず、仕組みが単純 |
| 隠す情報 | ルールごとに「見る人に合わせて状態を加工する関数」を持たせ、サーバが必ず通す | 画面で隠すだけだと通信の中身を覗けば分かってしまうため、サーバで消す |
| 多言語 | 画面の文言を言語ごとの辞書ファイルに分け、サーバはエラーを「種類のコード」で返す | 言語を足すときは辞書を 1 つ増やすだけ。訳し漏れは型チェックで見つかる |

**用語の言い換え**
- トークン：その対局で「あなた本人」であることを示す合言葉。端末のブラウザに保存される
- 版（version）：盤面の通し番号。2 つの端末からほぼ同時に指したときの食い違いを防ぐのに使う
- ポーリング：一定間隔でサーバに「変化あった？」と聞きに行くやり方

## 9. 公開のしかたと費用の目安

| 方法 | 内容 | 月額の目安 |
| --- | --- | --- |
| 家の PC で動かす | 同じ Wi-Fi 内でのお試し向け | 0 円 |
| Fly.io / Render などにそのまま載せる | 今のコードをほぼそのまま公開できる。データ保存用のディスクを付ける | 0〜数百円 |
| Cloudflare Workers + D1 に移す | 無料枠が大きく、世界中で速い。保存部分（`store.ts`）の書き換えが必要 | 0 円（無料枠内） |

まずは 2 番目で公開し、遊ぶ人が増えたら 3 番目を検討する。

## 10. リスクと対策

| リスク | 対策 |
| --- | --- |
| ブラウザのデータを消すとトークンが消え、指せなくなる | 自分用リンクを控えておくよう案内。将来は任意のアカウント連携 |
| 自分用リンクを他人に送ってしまう（なりすまされる） | 画面に「他人に送らないで」と明記。将来はリンクの再発行機能 |
| 相手が放置して対局が終わらない | 持ち時間・時間切れ負けを第 2 版で入れる |
| 番が来ても気づかれない | 手番通知を第 2 版の最優先にする |
| 招待リンクが第三者に渡る | 招待リンクは 1 回参加されたら無効になる（実装済み） |
| 隠す情報が相手に漏れる | サーバで消してから送る。漏れないことを自動テストで確認している（実装済み） |
| タイ語・英語の訳が不自然 | 現在の訳は AI による。公開前にそれぞれの言語を話す人に見てもらう |
